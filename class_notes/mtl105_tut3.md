## Problem 3
### Number of generators of a cyclic group $G$ of order $d$ is $\phi(d)$
Let $G = \langle a\rangle$.

$\langle a^x\rangle = G$
$\iff a^x, a^{2x}, a^{3x}\dots a^{dx}$ are all distinct
$\iff ix \neq jx$ (mod d) for $1\leq i < j \leq d$
$\iff kx \neq 0$ (mod d) for $1\leq k \leq d-1 $
$\iff (x,d) = 1$ (1 direction is obvious. for the other, suppose it is true but (x,d) > 1. Then, d/(x,d) < d so k = d/(x,d) gives kx | d. contradiction.)

### Sum of $\phi(d)$ over $d|n$ is $n$
It is the sum of number of generators of each subgroup. Each element generates one and exactly one subgroup. So, 1 is added corresponding to each element in exactly one of the terms.

## Problem 5
### $S_n = \langle (1,2), (1,2,\dots ,n)\rangle$
Every permutation can be written as a product of 2-cycles. Every 2-cycle can be written as a product of consecutive 2-cycles. Therefore, any permutation can be written as a combination of consecutive 2-cycles.

If $j = i+k, k > 0,$ we have $(i,j) = (i,i+1)(i+1, i+2)\dots (j-1, j) (j-2, j-1)\dots (i, i+1)$. We prove this by induction on $k$. 

**Base case.** $j = i+1: (i, i+1) = (i, i+1)$. 

**Inductive step.** Suppose $j = i + k: (i, i+k) = (i,i+1)(i+1,i+k)(i,i+1) = (i, i+k)(i+1) = (i, i+k)$

Also, any consecutive 2-cycle, $(i,i+1) = (1,2,\dots ,n)^{-i+1}(1,2)(1,2,\dots ,n)^{i-1}$. Again we do this by induction on $i$.

**Base case.** $i=1:(1,2) = (1,2)$ 

**Inductive step.** $(i,i+1) = (1,2,\dots ,n)^{i-1}(1,2)(1,2,\dots ,n)^{-i+1} = (1,2,\dots, n)(i-1, i)(1,2,\dots, n)^{-1} = (1,2,\dots,n)(i-1,i)(n, n-1,\dots,2,1) = (i-1)(i,i+1) = (i,i+1).$

## Problem 6
### $x$ is the rotation counterclockwise by $\frac{2\pi}{n}$ and $y$ is some reflection.
Each $x^m y$ is distinct for $1 \le m \le n$ because $x^{m_1} y = x^{m_2}y\implies x^{m_1} = x^{m_2} \implies n\mid|m_1-m_2|\implies m_1 = m_2$ since $1 \le m_1, m_2 \le n$. Also, each $x^m y$ is a reflection because $x^m$ is a rotation and preserves orientation, whereas $y$ reverses the orientation. So overall, $x^my$ reverses the orientation. Therefore, $\{x^m:1\le m \le n\}$ gives the set of all reflections.
